# 0.3.0

## 亮点

- **文件放到 Google Drive，ChatGPT 自己去读**：`voyager ask --drive <文件|文件夹>` 用 rclone 上传到 `VOYAGER_DRIVE_REMOTE` 下的新文件夹，在提示里写文件 ID，由 ChatGPT 自己的 Google Drive 应用读取。不再受 64 MiB 限制（单个文件或 zip 最大 512 MiB），文件夹自动打成 zip、去掉密钥文件。rclone 的 Google 账号要和 ChatGPT 连的是同一个。
- **让 ChatGPT 直接读写你的仓库**：`voyager ask --repo owner/name[@ref]` 交给 ChatGPT 的 GitHub 应用，要求它只往新的 `chatgpt/*` 分支提交，你看过再合并。仓库没授权给 ChatGPT 时以退出码 3 停下，并告诉你去 github.com/settings/installations 加上。
- **回复里的文件自动下载**：`ask` 和 `read` 把 ChatGPT 回复里附带的文件和 `response.md` 一起存到 `output/files/`，加 `--no-files` 跳过。需要更新后的 Voyager 插件；旧插件照样能提问，CLI 会提示去更新。

## 其他

- `--drive` 和 `--repo` 只改提示，不需要新版插件。
